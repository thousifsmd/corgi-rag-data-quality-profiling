# IEEE template builder (paper-build tooling)

Scripts that generate the Word manuscript from the official IEEE conference template via Word COM
automation. **This is separate from the research code** (`fetch_*`, `clean_xbrl`, `corgi_*`,
`make_fig1`) and is **not needed to reproduce any experiment** — it only produces the paper file.

## Requirements
- Windows with **Microsoft Word** installed
- `pip install pywin32`
- The IEEE A4 conference `.doc` template (supply your own from your venue — not committed here)
- Figures generated by the research code (`../out/fig1_pipeline.png`, `../out/fig2_dose_response.png`)

## Scripts

| Script | Purpose |
|---|---|
| `word_convert.py` | Open the IEEE `.doc` template, save a `.docx` copy, and dump its named styles. |
| `word_fill.py` | Fill the template with the paper's title, author, abstract, sections, tables, and figures, using the template's own styles. The `BODY` list is the single source of the manuscript content. |
| `verify_refs.py` | Cross-check each reference against Crossref (titles/venues/years/pages). |

## Usage

```bash
# inspect template styles / make a .docx copy
python word_convert.py "../Conference-template-A4.doc" "../paper/CORGI_paper.docx"

# build the manuscript (idempotent — opens the original template fresh each run)
python word_fill.py "../Conference-template-A4.doc" "../paper/CORGI_paper.docx"

# sanity-check the reference list
python verify_refs.py
```

## Layout notes (hard-won)
`word_fill.py` reproduces the IEEE layout by:
1. deleting the template's example body **within its section only** (preserving the 2-column section's
   final paragraph mark / sectPr);
2. deleting the template's floating example **text boxes** (`doc.Shapes`) — our figures are inline;
3. setting the **title+author section to 1 column** (centers them full width, keeps the Abstract on
   page 1) and the **body section to 2 columns** (18 pt gutter).

Do **not** flatten sections, `InsertBreak`, or force other sections' columns — the template's section
breaks render as page breaks and those operations either make the title 2-column or push the body to
a blank page 2.

## ⚠️ Author identity / double-blind
`word_fill.py` contains the author name/affiliation (author block) and the full manuscript text.
For a **double-blind** submission, do **not** include these scripts (or the manuscript) in the
anonymous review repo — add them post-acceptance. For single-blind venues or journals, they're fine.
Edit the author block and `BODY` content directly in `word_fill.py`, then re-run.
